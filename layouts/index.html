What is go-vcs?

A Git forge small enough to read and strict enough to trust: repository hosting, a web UI, an administration API over gRPC with FIDO2 on the privileged operations, and Actions runners scheduled through GARM.

It is early. The admin gRPC API and its CLI are implemented; hosting, sign-in and the web UI are still design only. The design is written down in forge/docs/design.md; what is not built yet is not presented here as if it were.
